# Library Management System

## Project Description

A Java-based Library Management System developed
using Object-Oriented Design principles.

## Technologies

- Java 17
- Maven
- Java Collections Framework
- IntelliJ IDEA / Eclipse

## Main Features

- User management
- Book management
- Borrowing books
- Returning books
- Viewing borrowed books
- Overdue notifications

## Design Patterns

1. Factory Pattern
2. Singleton Pattern
3. Observer Pattern

## OOP Concepts

- Abstraction
- Encapsulation
- Inheritance
- Polymorphism

## User Types

Student:

- Borrowing period: 14 days

Teacher:

- Borrowing period: 30 days

## How to Run

Compile:

mvn clean compile

Run:

mvn exec:java
